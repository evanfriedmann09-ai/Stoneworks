# Stoneworks

An original voxel sandbox game. Every texture, sound and song is generated by the game itself.

## Download

Get the newest version from **[Releases](https://github.com/evanfriedmann09-ai/Stoneworks/releases/latest)**:

| Your computer | File |
| --- | --- |
| Mac with Apple chip (M1 or newer) | `Stoneworks-mac-arm64.zip` |
| Mac with Intel chip | `Stoneworks-mac-x64.zip` |
| Windows | `Stoneworks-windows-x64.zip` |
| Any computer, in Chrome or Edge (no install) | `Stoneworks.html` |

**Mac:** unzip, drag **Stoneworks** into Applications and open it. The first time, macOS says it can't
verify the app: click Done, then go to System Settings → Privacy & Security and click **Open Anyway**.

**Windows:** unzip, open the **Stoneworks** folder and run `Stoneworks.exe`. If SmartScreen appears,
click **More info → Run anyway**.

The game checks this page for new versions and shows them on its title screen. To update, download the
new version and replace the old one; your worlds stay.

## Playing together

In your world press Esc → **Open to Friends** and choose:

- **Internet:** friends anywhere choose Multiplayer → Internet and type your game code.
- **Your network:** friends on the same Wi-Fi see your game under Multiplayer → Your network.
